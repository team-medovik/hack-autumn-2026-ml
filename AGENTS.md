# Правила проекта

## Реализация новых фич

Для реализации каждой новой фичи необходимо соблюдать следующий процесс:

1. Переключиться на ветку `develop` и подтянуть её актуальное состояние из удалённого репозитория.
2. Создать от обновлённой ветки `develop` новую ветку с именем вида `feature/*`.
3. Выполнять всю работу над фичей только в созданной ветке.
4. Писать сообщения коммитов на русском языке, ясно и понятно описывая внесённые изменения.
5. После завершения работы отправить ветку в удалённый репозиторий и создать pull request.
6. Не выполнять merge pull request — слияние должно оставаться отдельным действием после ревью.
