# Aeza VPS/VDS — ML риска непродления

Текущая разработка: [OpenAPI-контракт](contracts/openapi.yaml),
[постоянный генератор с PostgreSQL и FastAPI](generator_service/README.md) и
[пошаговая симуляция с восстановлением](examples/risk/event-driven/LIVE_STATE.md).
Основная ветка — `main`, интеграционная — `develop`, новые работы — `feature/*`.
Лёгкий CI проверяет генератор и подготовку признаков без обучения CatBoost.

ML-часть проекта [hack-autumn-2026-api](https://github.com/team-medovik/hack-autumn-2026-api),
выделенная в самостоятельный репозиторий с историей изменений.
Модель пока **не подключена к API**. Синтетические результаты не подтверждают
качество прогнозов на реальных клиентах.

## Структура

- `ml/` — признаки, метки, обучение CatBoost, проверки и отчёты.
- `generator_service/` — независимые worker и HTTP API генератора; без вызовов ML.
- `examples/risk/` — генераторы, каталог тарифов и сохранённые синтетические события.
- `src/test/resources/risk/data.json` — исходный JSON кейса для генераторов и проверок;
  это fixture, а не исходники API.
- `outputs/event-driven-logloss-20261025/` — таблица сравнения всех прогнозов.

Вложенность `ml/` сохранена намеренно: команды выполняются из корня этого
репозитория, без зависимости от соседнего checkout API.

## Запуск

```sh
python3.13 -m venv ml/.venv
ml/.venv/bin/python -m pip install -r ml/requirements-lock.txt
ml/.venv/bin/python -B -m unittest discover -s examples/risk/event-driven/tests
ml/.venv/bin/python -B -m unittest discover -s ml/tests
```

Текущий эксперимент: [обучение и сравнение моделей](ml/EVENT_DRIVEN_TRAINING.md).
Схема данных: [признаки и метки](ml/EVENT_DRIVEN_DATASET.md).

Подготовленные `rows.jsonl`, модели и результаты `ml/runs/` исключены из Git.
На рабочем компьютере они перенесены вместе с кодом, но новый clone их не получит.
Окружение `.venv` создаётся заново; в Git его нет.
Источники событий, manifests и отчёты сохранены в репозитории.
Команды воспроизведения описаны в отчётах; сравнение со старой моделью требует
её артефакта или воспроизведения соответствующего исторического эксперимента.
